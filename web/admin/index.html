Deliberately not bought in v1

  • Active radar (EUR 30k–160k) — more than the whole budget; integrate a partner's later via API.
  • Jammer / any transmit device — cannot legally be placed on the Polish market at all.
  • EO/IR thermal camera — cost, trigger interface, privacy obligations. v2.
  • AntSDR E200 (DJI DroneID, ~2,450 PLN) — valuable, but waits for a pilot.
  • Test drone — borrow first; separate budget and legal review (insurance since 13 Nov 2025).
  • Ground sensors (MLX90640 thermal array, PIR) — software is ready; buy only after HERMES phase 1 passes and a buyer asks (D5).

Ordering checklist — do not skip

  1. Test plan agreed before any order.
  2. Software running and tested on simulated data (Phase 0 gate passed).
  3. Confirm KrakenSDR price and stock; ignore scalper listings (USD 1,271+).
  4. Confirm the outdoor 868 MHz antenna set and that the enclosure fits the connectors.
  5. Decide VAT: a private purchase pays 23% irrecoverably.
  6. Buy node 1 only. Node 2 after Phase 1 gates pass.

Assembly

Written before the hardware arrives, on purpose, so the order can be checked against it. Full version in hardware/assembly.md.

Physical build

  1. Array layout. Five antennas in a circle, radius from the band (868 MHz → 0.15 m). Mark antenna 1 and note which direction it points.
  2. Connections. Antenna 1 → Kraken channel 1, in rotational order. Same rotation in software, or every bearing mirrors.
  3. Power. Powered USB hub for the KrakenSDR, its own PSU for the Pi. Brownouts show up as coherence failures.
  4. Enclosure. Antennas outside, receiver inside, shortest coax. Outdoor antennas, not the magnet set.
  5. Surge protection on the mast run. A strike takes out everything at once.
  6. Network. Static LAN address. Record it.

Software bring-up — in order

  1. Receiver visible — OS sees all five channels.
  2. Coherence calibration with the noise source. If it fails or drifts, stop — nothing downstream is trustworthy.
  3. Known-transmitter baseline at a known true bearing. Record the error in degrees.
  4. Repeat 5× at different yaws — constant error (fixable offset) vs random (multipath/SNR).
  5. Feed the capture into czapla.doa; it should match the vendor tool within a few degrees.
  6. Full chain: one event reaches the store and generates a Polish report (T-7, T-9).
